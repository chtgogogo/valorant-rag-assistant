# 卡 #5：点踩 badcase 回流评测集
- 目标：一条命令把点踩记录导出为评测集候选，打通"用户反馈→评测资产"的回流管线（面试讲数据驱动迭代的核心素材）。
- 涉及文件：
  - 新建 `backend/scripts/export_feedback_to_eval.py`
  - 新建 `backend/eval/badcase_candidates.jsonl`（脚本产物）
- 前置依赖：卡#4 已完成（需要有 feedback.db 与数据）
- 实现要点：
  1. 脚本读 `backend/data/feedback.db` 中 `rating='down'` 的记录，逐条转成 JSONL：`{"question": ..., "reference_answer": <该次AI原答案,标注为"待人工复核">, "source": "user_thumb_down", "session_id": ..., "exported_at": ...}` 追加写入 `backend/eval/badcase_candidates.jsonl`；
  2. 幂等：同一 feedback id 不重复导出（在 JSONL 行里带 feedback_id，导出前扫描已有行去重）；
  3. 跑通验证：先往 feedback.db 手工 INSERT 一条 rating='down' 测试记录 → 跑脚本 → 确认 JSONL 出现该条 → 再 INSERT 同一条变体 → 复跑确认不重复 → 最后清理测试数据（DELETE 测试行并从 JSONL 移除测试行）。
- 验收（怎么算做完）：
  - `python backend/scripts/export_feedback_to_eval.py` 退出码 0，输出导出条数；
  - 幂等性验证按实现要点 3 走完一遍，贴命令输出；
  - 测试数据清理后 `feedback.db` 与 JSONL 均无测试残留。
