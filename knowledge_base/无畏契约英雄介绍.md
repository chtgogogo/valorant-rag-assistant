 # 无畏契约英雄介绍
 
 ## 英雄定位系统
 
 无畏契约中的英雄分为四个定位：**决斗者**、**先锋**、**烟位**、**哨位**。每个定位在团队中承担不同职责。
 
 以下英雄名称格式为：**国服ID / 港服ID / 外服ID(英文)**，方便不同服务器玩家查询。
 
 ---
 
 # 决斗 — 突破与击杀
 
 决斗者是团队的尖刀，承担突破防线、拿首杀、制造人数优势的职责。适合枪法好、反应快的玩家。

 # 英雄选择建议
 
 ## 新手推荐
 - 决斗：不死鸟(有自疗、操作简单) > 雷兹(范围伤害好上手)
 - 先锋：猎枭(信息获取直观) > 斯凯(有治疗功能)
 - 烟位：炼狱(烟雾操作简单) > 幽影(需要练习传送)
 - 哨位：贤者(辅助定位容错高) > 奇乐(防守位置固定)
 
 ## 进阶推荐
 - 决斗：捷风(上限极高) > 芮娜(枪法自信可选)
 - 先锋：暮蝶(信息获取强) > KAY/O(技能压制)
 - 烟位：蝰蛇(区域控制强) > 星礫(操作上限高)
 - 哨位：零(信息收集全面) > 钢索(控制能力强)
 
 ## 团队阵容搭配建议
 - 标准阵容：1决斗 + 1先锋 + 1烟位 + 2哨位(或1哨位+1先锋)
 - 快攻阵容：2决斗 + 1先锋 + 1烟位 + 1哨位
 - 防守阵容：1决斗 + 1先锋 + 2烟位 + 1哨位
 - 双决斗阵容：2决斗 + 1先锋 + 1烟位 + 1哨位(适合强枪法队伍)

 ## 新英雄动态（2026）
