# 无畏契约经济系统详解

经济（买枪的钱）是无畏契约战术的底层逻辑。看不懂经济就看不懂"为什么这局不买枪"。

## 一、钱的来源

| 来源 | 金额 | 说明 |
|------|------|------|
| 回合开始基础工资 | 3000 | 每回合都有，输了也有 |
| 击杀奖励 | 200/个 | 击杀方式不影响金额（刀、狙、枪都是200） |
| 下包奖励 | 300 | Spike（包）放下后全队+300，即使这回合输了 |
| 拆包奖励 | 300 | 成功拆掉Spike的队友获得 |
| 连败补偿 | 1900/2400/2900 | 连败第二、三、四回合递增（封顶2900） |
| 胜利奖励 | 3000 | 赢下回合全队+3000 |

**关键理解**：
- 连败补偿是"翻盘机制"——连败几局后钱反而不少，这是强行起枪的好时机。
- 下包的300是全队收入：进攻方"打不下也要下包"，这回合输了钱也不白打。

## 二、回合类型黑话

- **Eco局（白给局/省钱局）**：全队不买枪或只买手枪，把钱攒到下一回合。目的：下一回合全队满配。
- **Force局（强行起枪/强起）**：钱不多但硬买。通常出现在"赛点局保枪失败后"或"连败补偿足够时"。
- **半起（半买）**：买护甲+SMG（骇灵/蜂刺）或一把步枪不带甲。
- **Full Buy（满配）**：步枪（幻影/狂徒 3900）+ 重甲（1000）+ 技能，全队≥3900就可以满配。
- **保枪（Save）**：这回合打不赢了，躲起来保住枪留到下回合。保枪的枪下回合还在。

## 三、进攻方经济决策

1. **手枪局（第1回合）**：标配免费。推荐买法：800全花（幽灵500+技能300 或 短喷+技能）。
2. **第2回合的抉择**：
   - 手枪局赢了→第2回合可以买狙（飞将）或半起，压制力拉满；
   - 手枪局输了→第2回合大概率Eco，攒到第3回合满配（第3回合约5900/人）。
3. **下包价值**：进攻方哪怕2v4打不下点，Spike下了就+300全队，且防守方必须回来拆，可能创造保枪机会。
4. **翻盘局心态**：连败补偿到手后（2900+余款），果断全队同步起枪打一波，别各买各的。

## 四、防守方经济决策

1. **防守方没有下包奖励**，连败后经济更紧张，更依赖团队同步决策。
2. **保枪文化**：防守方3打5且包没下时，果断撤退保枪。一把3900的枪保存下来=下回合多3900预算。别"头铁1v3"送掉枪。
3. **烟位/哨位的技能优先级**：穷的时候先买技能后买枪——炼狱的烟、零的绊线不吃经济也能发挥（技能便宜）。

## 五、团队同步规则（最重要）

经济大忌是"三人满配两人手枪"——阵容强度断层，团战必输。

- **跟队买法**：以队伍中"钱最少的人"为标准。他只能半起，全队就半起。
- **指挥报经济**：开局买枪阶段报一句"我2800起不了，这局eco"，全队统一。
- **强制同步起枪时机**：连败补偿回合、赛点局（输了比赛就结束，攒钱没意义）、上半场最后一回合（下半场经济重置为800，上半场的钱带不过去）。

## 六、武器性价比速查

| 局面 | 推荐购买 | 理由 |
|------|------|------|
| 手枪局 | 幽灵500 / 短喷150+技能 | 幽灵精准度高；短喷近角阴人 |
| Eco局 | 骇灵1600 或 全Eco只买技能 | SMG经济局性价比之王 |
| 半起局 | 骇灵+轻甲 或 飞将950 | 攒钱与战力的平衡 |
| 满配局 | 幻影/狂徒3900+重甲1000+技能 | 标准战斗力 |
| 狙击局 | 飞将950(轻狙) / 冥狙4700 | 冥狙需要全队富养；莽侠2400是折中选择 |
| 反 Eco 局 | 小心：白枪局敌人近战强 | 站位拉开距离，别被白嫖 |

## 七、常见经济问题解答

- **Q：为什么赢了要买狙，输了反而要Eco？**
  A：赢的一方每人多3000+保枪，第2回合预算高，可以买950轻狙扩大优势；输的一方靠连败补偿，第3回合才能全队满配，第2回合强行买会打乱节奏。

- **Q：钱到10000会封顶吗？**
  A：会，9000封顶。钱满时这回合必须花（买枪买技能），不然浪费。

- **Q：死掉的队友的枪能捡吗？**
  A：能。捡敌人的枪也是经济手段——穷局捡一把幻影等于赚3900。

- **Q：上半场和下半场的经济互通吗？**
  A：不互通。换边后所有人重置为800信用点，武器清空（护甲保留一部分），这就是"下半场第1回合=新手枪局"。
