# 无畏契约经济系统详解（修正版）

> 最后核对：2026-09-17
> 说明：经济数值以 VALORANT 当前版本游戏内结算为准；不同版本可能有微调。

## 一、钱的来源

| 来源 | 金额 | 说明 |
|------|------|------|
| 回合胜利 | +3000 | 赢下回合后每人获得，不是每回合基础工资 |
| 连败补偿 | 1900 / 2400 / 2900 | 第 1 / 2 / 3 次及以后连败；封顶 2900 |
| 击杀 | +200/个 | 使用任何武器击杀都是 200 |
| 助攻 | 0 | VALORANT 没有助攻奖金 |
| 下包 | +300 | 成功安放 Spike 的奖励 |
| 拆包 | +300 | 成功拆除 Spike 的奖励 |

**关键理解：**
- 没有每回合基础工资 3000 这种机制；3000 是胜利奖励。
- 连败补偿从 1900 开始，连续输到第 3 回合及以后封顶 2900。
- 下包即使回合输了，也能拿到下包奖励；所以打不下也要下包是正确思路。

## 二、回合类型

- **Eco / 白给局**：全队少买或不买，攒钱到下一回合。
- **Force / 强起**：经济不够也强行买，争翻盘。
- **半起 / 半买**：轻甲 + 冲锋枪，或步枪不带甲。
- **Full Buy / 满配**：步枪 2900 + 重甲 1000 + 技能，约 4400 左右。
- **Save / 保枪**：打不赢时保枪，枪下回合还能用；护甲不跨回合保留。

## 三、进攻方经济

1. 手枪局：标配免费；800 可以买鬼魅 + 技能，或短炮 + 技能。
2. 手枪局赢了：第 2 回合可以半起或起轻狙扩大优势。
3. 手枪局输了：第 2 回合通常 Eco，第 3 回合再根据连败补偿决定强起或满配。
4. 下包有奖励，且能逼迫防守方回防，是劣势局的重要经济来源。

## 四、防守方经济

1. 防守方没有下包奖励。
2. 3v5 且包没下时，优先保枪，不要硬送。
3. 穷的时候技能优先级因英雄而异：烟雾、绊线、摄像头这类信息/控制技能往往比强行起枪更有价值。

## 五、团队同步

- 以队伍里钱最少的人为标准决定这回合买不买。
- 指挥要在购买阶段统一报经济。
- 连败补偿回合、赛点局、上半场最后一回合，是常见的强起/全买节点。
- 换边后经济重置为 800，上半场的钱不带到下半场。

## 六、常见问题

- **钱会封顶吗？** 会，上限 9000；快满时要在购买阶段花掉。
- **护甲会保留吗？** 不会，每回合都要重新购买护甲。
- **助攻有钱吗？** 没有，只有击杀 +200、下包/拆包 +300。
- **输了为什么还有钱？** 来自连败补偿，1900 / 2400 / 2900。
