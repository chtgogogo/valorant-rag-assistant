 # 无畏契约地图攻略

> 最后核对：2026-09-17
> 地图名以 valorant-api.com zh-CN 为准；点位细节以游戏内实测为准。
 
 ## 地图概述
 
 无畏契约的地图设计围绕两个爆破点(A点和B点，部分地图有C点)展开，攻防双方围绕点位控制进行博弈。每张地图都有独特的地形和战术要点。
 以下地图名称格式为：**国服ID / 外服ID(英文)**。
 
 ---
 
 # 源工重镇
 
 ## 地图特点
 - 双点位地图（A点、B点），没有中点
 - 两个点位各有一个单向传送门：A点传送门通往B点观察室，B点传送门通往A点淋浴间
 - 传送门是绑定的核心机制，可以快速转点
 - 地图结构紧凑，无需中路控制，攻防节奏快
 
 ## A点攻略
 - **进攻方**：从淋浴间或传送门进入，烟雾弹封锁A点入口和花园方向。可以利用传送门声东击西
 - **防守方**：控制淋浴间和传送门出口。哨位英雄在A点部署防守装置。A点箱子后是常用架枪位
 - **关键位置**：淋浴间、花园、传送门出口、A点大箱、高台
 - **推荐英雄**：猎枭（A长侦察）、零（传送门出口陷阱）、奇乐（A点防守设备）
 
 ## B点攻略
 - **进攻方**：从B点长廊或B点窗口进入，需要清理钩子位和后方角落。推车位置是常见对枪位
 - **防守方**：控制B点长廊视野，利用钩子位和窗口架枪。B点后方高台可以掩护队友
 - **关键位置**：B长廊、钩子位、B窗口、B后方、大箱后
 - **推荐英雄**：蝰蛇（B长毒墙封路）、炼狱（B点快速烟雾）、贤者（B窗口冰墙）
 
 ## 传送门战术
 - 进攻方可以利用传送门快速转点，让防守方措手不及
 - 防守方可以在传送门出口设伏
 - 零的陷阱线放在传送门出口非常有效
 - 使用传送门时注意声音提示，敌人可以提前准备

 # 隐世修所
 
 ## 地图特点
 - 三点位地图（A点、B点、C点），地图较大
 - 中间B点连接A点和C点，防守压力大
 - 进攻路线多，战术变化丰富
 - 每个点位都有多条进攻路线，防守方需要合理分配人员
 
 ## A点攻略
 - **进攻方**：从A短、A长、中转A三条路线进攻，需要控制车库
 - **防守方**：控制A短入口，利用车库和A后方架枪
 - **关键位置**：A短、A长、车库、A后方塔楼
 - **推荐英雄**：幽影（A长烟雾封锁）、雷兹（A短爆破突进）
 
 ## B点攻略
 - **进攻方**：从中或B窗口进入，B点空间小烟雾弹效果显著
 - **防守方**：控制B窗口和中路连接，B点内用陷阱封锁
 - **关键位置**：B窗口、中路、B点后方
 - **推荐英雄**：奇乐（B点防守设备）、捷风（B窗口冲刺进点）
 
 ## C点攻略
 - **进攻方**：从C长、C短、中转C进攻，C长是开阔地带需要烟雾弹
 - **防守方**：控制C长视野，利用C后方平台架枪
 - **关键位置**：C长、C短、C后方平台、车库
 - **推荐英雄**：猎枭（C长侦察箭）、贤者（C平台冰墙封路）

 # 亚海悬城
 
 ## 地图特点
 - 双点位地图（A点、B点），中路较大
 - 意大利风格建筑，开阔地带多
 - 两个点位都有可开关的铁门
 - 中路是双方争夺最激烈的地带
 
 ## A点攻略
 - **进攻方**：从A主道或中转A进攻，需要控制花园和酒庄
 - **防守方**：利用铁门控制A点入口，在花园和酒庄架枪
 - **关键位置**：A主道、花园、酒庄、A点铁门
 - **推荐英雄**：幽影（A长烟雾）、蝰蛇（A点毒墙）
 
 ## B点攻略
 - **进攻方**：从B主道或中转B进攻，需要清理市场和B后方
 - **防守方**：控制B主道和市场，利用B高台架枪
 - **关键位置**：B主道、市场、B高台、B点铁门
 
 ## 中路攻略
 - 中路开阔，是双方争夺焦点
 - 有多个入口连接A点和B点
 - 控制中路可以分割防守方注意力

 # 霓虹町 / Split

 ## 地图特点
 - 双点位地图（A点、B点），中部被大楼分隔为A大、中路、B大三条通道
 - 标志性机制是**绳索升降机（Rope Ascender）**：攻防双方各有一条绳索可以快速上到中路高层平台
 - 中路控制价值极高，中路打通后可以快速包夹两个包点
 - 地图狭小、交火距离近，适合近战强、滑行机动快的英雄（如霓虹、雷兹）

 ## A点攻略
 - **进攻方**：从A大推进或从中路高层平台包夹A点。A点是"高台包点"，需要处理上方架枪位
 - **防守方**：A大入口和A高层平台是两条关键枪线，狙击英雄（冥驹）常架A大长道
 - **关键位置**：A大、A高台、屏幕位、A小、教堂

 ## B点攻略
 - **进攻方**：B主推进或从中路转B。B点入口狭小，需要烟雾+闪光组合突破
 - **防守方**：控制B主入口和中路B方向视野，包点后侧是经典阴人位
 - **关键位置**：B主、B点高台、市场、B连接、输了位

 ## 中路争夺
 - 中路是霓虹町的兵家必争之地：控制中路即可快速转点、包夹
 - 防守方常用哨位技能（绊线、炮塔）封锁中路高层
 - 进攻方拿下中路后，A、B两点的进攻选择都会大幅增加

 # 天枢云阙

 ## 地图特点
 - 2026年6月随赛季第四幕上线的**首张中国风地图**，设定为山谷中的源能者训练学院，有训练大厅、冥想花园等场景
 - 标志性机制是**可降式墙体**：部分墙体可以在回合中降下，战场结构会动态变化，不能死记固定路线
 - 结构开阔与窄道并存，攻防博弈围绕"何时降墙、往哪转点"展开

 ## 攻防要点
 - **进攻方**：利用墙体降下机制打时间差，声东击西后快速转点；降墙瞬间是最佳突袭窗口
 - **防守方**：不要依赖固定枪线，墙体降下后原有掩体会消失，需要预判降墙后的第二防线
 - **关键位置**：训练大厅、冥想花园、中央庭院（以游戏内实际标注为准）

 # 地图池轮换说明

 - 无畏契约竞技模式采用**地图池轮换**机制，同一时间只有约7张地图进入竞技匹配队列
 - 每个赛季（幕）官方会轮换地图：例如2026赛季第三幕源工重镇退出、亚海悬城回归；第四幕新增天枢云阙；第五幕微风岛屿退出、幽邃地窟加入
 - 被轮换出图池的地图仍可在其他模式（如非竞技模式）中游玩
 - 上分前先查看当期图池，针对性练习图池内地图性价比最高

 # 通用地图技巧
 
 ## 进攻方技巧
 1. **烟雾弹使用**：封锁防守方架枪位置，创造安全进攻路线
 2. **闪光弹配合**：突进前扔闪光，致盲防守方
 3. **信息收集**：用猎枭的追踪箭、零的摄像头等获取防守方位置
 4. **假打转点**：在一个点制造声响后快速转点
 5. **默认站位**：不要一开始就全力冲一个点，先收集信息
 6. **同时进攻**：多人同时从不同入口进攻，分散防守火力
 
 ## 防守方技巧
 1. **交叉火力**：队友之间形成交叉枪线，让进攻方无法同时应对
 2. **信息收集**：用陷阱、摄像头等提前发现进攻方向
 3. **回防时机**：不要过早回防，确认进攻方向后再转点
 4. **经济管理**：eco局时合理选择站位，不要硬拼
 5. **利用高低差**：高处对低处有视野和命中优势
 6. **前顶侦察**：回合初期前顶获取信息，但注意不要送人头
 
 ## 特殊机制
 1. **传送门**：部分地图有传送门，可以快速转点
 2. **绳索**：可以快速垂直移动，但使用时有声音
 3. **可开关门**：可以控制进攻路线，但注意敌人在门后
 4. **可破坏墙壁**：部分墙壁可以破坏，创造新的射击路线
 
 ## 地图控制节奏
 - **回合初期(0-30秒)**：争夺关键位置控制权，获取信息
 - **回合中期(30-70秒)**：确定进攻方向，准备突破
 - **回合后期(70-100秒)**：执行进攻或全力防守
 - **攻防转换**：进攻方转为防守，防守方转为进攻
