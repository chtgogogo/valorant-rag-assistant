## 知识更新说明

- 英雄/地图/武器名单已于 2026-09 联网核对过国服官网（新增：钛狐、幻棱、夜露、尚勃勒、迷核简介、霓虹町、天枢云阙、莽侠、追猎）。
- 游戏持续更新，建议每隔几个赛季重新核对英雄名单、地图池和新武器，更新后运行重新索引。

## 更新流程

1. 编辑或新增本目录下的 `.md` 文件。
2. 运行项目根目录的 `重新索引.bat`，或手动执行：
   ```bash
   cd backend
   python scripts/init_knowledge_base.py
   ```
3. 脚本会清空旧向量库、把本目录文档同步到 `backend/data/uploads/` 并重新向量化。
