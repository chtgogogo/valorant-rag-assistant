# 知识库源文件

本目录存放可版本管理的无畏契约知识库 Markdown 源文件。

## 文件说明

| 文件 | 说明 |
|------|------|
| 无畏契约英雄介绍.md | 英雄定位、技能、玩法技巧 |
| 无畏契约武器图鉴.md | 武器属性、价格、使用建议 |
| 无畏契约地图攻略.md | 地图点位、攻防战术、通用技巧 |
| 无畏契约新手攻略.md | 基础规则、经济、射击、上分 |
| 无畏契约进阶战术与阵容体系.md | 阵容搭配、默认战术、回防/转点、经济决策 |
| 无畏契约枪械控制与训练方法.md | 压枪、急停、预瞄、训练计划 |
| 无畏契约权威数据与官方资料导航.md | 官方/权威数据源和知识校验清单 |
| 无畏契约学习教程与视频资源.md | B站/抖音教程入口、检索关键词、学习路径 |

## 更新流程

1. 编辑或新增本目录下的 `.md` 文件。
2. 运行项目根目录的 `重新索引.bat`，或手动执行：
   ```bash
   cd backend
   python scripts/init_knowledge_base.py
   ```
3. 脚本会清空旧向量库、把本目录文档同步到 `backend/data/uploads/` 并重新向量化。
