# 无畏契约游戏术语黑话大全

> 最后核对：2026-09-17

玩家口语和游戏机制名词对照。本篇是理解队友报点、攻略视频、社区讨论的"词典"。

## 一、局内状态与经济术语

| 术语 | 含义 |
|------|------|
| Eco / 白给局 / 省钱局 | 全队不买枪攒钱的回合 |
| Force / 强起 | 钱不够也强行买枪 |
| 半起 / 半买 | 买SMG或轻甲的中间态 |
| 满配 / Full Buy | 步枪+重甲+技能全买 |
| 保枪 / Save | 打不赢就躲，保住枪下回合用 |
| 白枪局 | 敌人全员没枪（纯手枪/刀）的回合，小心被近身 |
| 连败补偿 | 连续输回合后系统给的额外工资（1900/2400/2900递增） |
| 上分 / 掉分 | 排位升段位/降段位 |
| 赛点 | 再赢一局就获胜的比分（如12:11） |
| 赛点局 | 拿下就赢整场的回合 |
| 翻盘局 | 落后很多追回来的局 |

## 二、战术行动术语

| 术语 | 含义 |
|------|------|
| Rush | 全队快速冲一个点（如 Rush B：全员直冲B点） |
| Default / 默认打法 | 开局全员分散占住地图关键区域，先控图再找机会 |
| 执行 / Execute | 集中技能强攻包点的瞬间（烟+闪+震同步交） |
| 假打 / Fake | 在A点制造动静吸引回防，实际转攻B点 |
| 转点 / Rotate | 攻方换攻另一个点；守方从A赶去B支援 |
| 回防 / Retake | 包下了之后防守方重新夺回包点 |
| 拉枪线 / 拉边 | 从掩体侧边横移出去暴露视野开枪，"拉出去打" |
| 对枪 / Duel | 两人在同一枪线上互相开火 |
| 枪线 / Angle | 一个位置能看到的视野通道 |
| 架枪 / Holding | 预瞄一个枪线等人出现 |
| 预瞄 / Pre-aim | 转角前把准星提前放在敌人可能出现的位置 |
| 清点 / Clear | 逐个检查包点每个角落 |
| 拆包 / Defuse | 拆除已下放的 Spike：长按 7 秒；3.5 秒为半拆，中断后进度重置 |
| 下包 / Plant | 在包点安放Spike |
| 蹲坑 / Camp | 躲在一个角落不动等人经过 |
| 绕后 / Flank | 绕到敌人背后偷袭 |
| 残局 / Clutch | 队友全灭后1打多的局面（1v3叫"一穿三残局"） |
| 一穿二 / 一穿三 | 一个人连续击杀2/3个敌人 |
| Eco局狙 / 白给狙 | 穷局硬买狙（贬义：经济乱打） |
| 反eco | 我方满配打对面白枪局，此时要拉开距离打，别被近身换 |

## 三、位置与报点术语

| 术语 | 含义 |
|------|------|
| A大 / B主 | 进攻A点/B点的主干道 |
| A小 / B小 | 进入包点的次要小通道 |
| 中路 / Mid | 地图中央区域 |
| 连接体 / Connector | 连接中路与包点的通道 |
| 高台 / 天堂 / Heaven | 包点上方的制高点（俗称天堂） |
| 地下 / 下路 / Hell | 低于主地面的通道（与天堂相对） |
| 一楼 / 二楼 | 建筑的楼层位置 |
| 包点箱后 / 大箱后 | 包点内大箱子的后面（常见蹲坑位） |
| 阴人位 | 视野死角里蹲守的位置 |
| 出生点 / 家 | 双方开局的位置 |
| 前点 / 压前 | 防守方前压到地图中部布防 |
| 侧翼 / 边路 | 主战场的侧面包抄通道 |

## 四、操作与技巧术语

| 术语 | 含义 |
|------|------|
| 急停 / Counter-strafe | 移动中瞬间按反方向键让准星恢复精度再开枪 |
| 压枪 | 连发时向下/左右拖动鼠标抵消后坐力 |
| 甩枪 / Flick | 快速把准星甩到目标上开枪 |
| 跟枪 / Tracking | 准星跟着移动目标持续开火 |
| 爆头线 / 头线 | 准星保持在敌人头部高度（约墙上一条线） |
| 蹲打 / Crouch-peek | 蹲下开枪（精度高但移动轨迹可预测） |
| 大拉 / 小拉 | 拉枪线时暴露的身体多（大拉）还是少（小拉） |
| Peek / 探头 | 从掩体后暴露视野的动作 |
| Swing / 摆动探头 | 队友配合两人先后快速拉枪线 |
| 跳狙 | 跳起空中开镜落地瞬间开枪的技巧 |
| 保ping / 卡视角 | 利用视觉死角让自己先看到敌人 |

## 五、游戏机制名词

| 术语 | 含义 |
|------|------|
| Spike / 包 | 进攻方的爆破装置 |
| 回合 | 一局内的单回合（攻守各有12回合，先赢13回获胜） |
| 加时赛 / OT | 12:12后进入的决胜机制 |
| 半场 / 换边 | 上半场12回合后攻守互换，经济重置为800 |
| 段位 | 排位等级：黑铁→青铜→白银→黄金→铂金→钻石→超凡入圣→神话→辐能战魂(最高) |
| 评分 / RR | 排位积分，赢+输- |
| 隐藏分 / MMR | 系统内部的实力评估值 |
| 技能点 / 大招点 | 击杀/下包/捡球积累，攒满可放大招 |
| 信用点 / 钱 | 买枪买技能的回合内货币 |
| 甲 / 护甲 | 轻甲25点(600元)、重甲50点(1000元) |
| Eco奖励 | 击杀固定+200，与武器无关 |
| 白给 | 无意义地送死送经济（贬义） |
| 亏了 / 赚了 | 一次交火的资源交换评估（换枪、换人数） |
| 三打五 / 3v5 | 剩余人数对比 |
| 残血 | 血量低于50 |
| 一滴血 | HP接近0（身上没甲状态） |

## 六、社区与性格梗（了解即可）

| 术语 | 含义 |
|------|------|
| 铁服 / 硬 | 敌人或队友"很猛"的意思 |
| 工具人 | 专门做侦察/开路脏活的位置 |
| 死斗 / TDM | 游戏内的团队死斗模式，练枪常用 |
| 竞技 / Ranked | 排位模式 |
| 娱乐模式 | 死斗、飞箭快攻、雪夜逃生等非排位玩法 |
| 车队 / 开黑 | 组队排位；单排 = 一个人排 |
| 修仙 / 通宵 | 深夜连续排位 |
| 上头 | 连败后情绪化继续排（通常越打越差） |
| 摆烂 / 挂机 | 消极游戏行为，会被举报 |
| 代练 | 花钱请人上分（违反游戏规则） |
| 破防 | 心态被打崩了 |
| 下饭 | 操作菜得让人"下饭"（调侃） |

## 七、按术语检索的建议

问助手时可以直接用黑话提问，例如：
- "eco局买什么好？" → 经济系统详解
- "怎么拆包？" → 新手攻略（拆包机制）
- "1v3残局怎么打？" → 进阶战术（残局思路）
- "什么是拉枪线？" → 本篇术语表 + 枪械控制篇
