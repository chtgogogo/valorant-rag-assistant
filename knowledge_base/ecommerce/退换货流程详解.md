# 退换货流程详解

## 退货与换货的区别

- **退货退款**：商品寄回，货款原路退回，交易结束；
- **换货**：商品寄回，商家寄出替换商品，不退款；换货产生的运费按"谁责任谁承担"原则处理。

## 标准退货流程（六步）

1. **发起申请**：订单详情页 →「申请售后」→ 选择退货退款，填写原因（质量问题/不想要了/尺寸不合等）；
2. **商家审核**：商家 **48 小时内**处理；超时未处理，系统自动同意申请；
3. **寄回商品**：审核通过后按页面显示的退货地址寄出，**务必填写退货物流单号**；
4. **商家验收**：商家签收后 **7 日内**完成验收；超时未处理，系统自动退款；
5. **退款到账**：验收通过后 **7 个工作日内**原路退回；
6. **完成**：可在账单中查看退款明细。

## 标准换货流程

1. 发起售后时选择「换货」，注明需要的替换规格（如颜色、尺码）；
2. 商家确认有货后给出寄回地址；
3. 寄出后填写物流单号；
4. 商家验收合格后 **48 小时内**寄出替换商品，运费到付或商家承担按责任划分；
5. 收到替换商品即完成换货。

## 各状态退款到账时间

| 支付方式 | 退款到账时间 |
|---|---|
| 原路退回（银行卡/第三方支付） | 验收后 1-7 个工作日 |
| 礼品卡 / 余额支付 | 退回礼品卡 / 余额，即时到账 |
| 分期付款 | 已还部分原路退回，未还部分冲抵账单 |

## 常见被拒原因与对策

1. **超过售后时效**：一般商品售后申请期为签收后 **90 天**（三包目录商品按三包期），超期可联系客服协商；
2. **商品影响二次销售**：剪吊牌、洗水、明显使用痕迹——寄回前请恢复原状、配件齐全；
3. **退货地址填错**：以售后申请页面显示的地址为准，不要用历史订单的旧地址；
4. **未填物流单号**：未填单号系统无法追踪，商家可暂停处理。

## 特殊场景

- **未收到货**：物流显示签收但实际未收到，先联系快递核查；确认丢失的可发起"仅退款"，平台介入核实后退款；
- **商品与描述不符**：拍照留证后发起售后，选择"描述不符"，商家承担来回运费；
- **订单已过售后期**：可提交人工工单说明情况，客服会按个案评估。
