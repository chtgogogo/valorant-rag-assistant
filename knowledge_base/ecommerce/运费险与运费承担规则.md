# 运费险与退货运费承担规则

## 运费险是什么

运费险（退货运费险）是在下单时一并投保的保险服务，投保后若发生退货，保险公司按保单约定**赔付退货运费**，一般保额 **10-25 元**，以投保页面显示为准。

## 运费险赔付规则

1. 退货成功（商家确认收货）后自动理赔，赔款 **72 小时内**到账支付宝或原支付账户；
2. 按商家首重运费与理赔额度**取低者**赔付，超出部分自担；
3. 换货一般不在运费险赔付范围（以保单条款为准）；
4. 理赔不需要申请，系统根据退货流程自动触发；未自动到账可在保单页查看理赔状态。

## 退货运费由谁承担

| 退货原因 | 运费承担方 |
|---|---|
| 商品质量问题、错发、漏发 | **商家承担**（买家先行垫付，商家赔付） |
| 七天无理由退货（非质量问题） | **买家承担**，有运费险的由运费险赔付 |
| 描述不符、假货 | 商家承担，平台先行赔付后向商家追偿 |

## 质量问题退货的运费报销

因质量问题退货的，运费实报实销（以普通快递标准为限）：

1. 买家先垫付运费寄回商品；
2. 在售后申请中上传**运费支付凭证**（快递单截图需含金额）；
3. 商家审核通过后，运费与货款一并原路退回；
4. 大件商品（家电、家具）质量问题退货，由商家安排上门取件，买家无需垫付。

## 谁的退货都需要知道的事

- 寄回商品请使用可查询的快递方式，保留物流单号直至退款到账；
- 到付件（商家未同意的）可能被拒收；
- 同一订单多次退货的，运费险一般只赔付一次。
