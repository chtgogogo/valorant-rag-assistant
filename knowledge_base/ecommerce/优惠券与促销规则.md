# 优惠券与促销规则

## 优惠券类型

| 类型 | 使用范围 | 叠加规则 |
|---|---|---|
| 平台通用券 | 全平台自营商品 | 可与店铺券叠加 |
| 店铺券 | 仅限发放店铺 | 不可与本店其他店铺券叠加 |
| 品类券 | 限指定品类 | 可与店铺券叠加，受优惠上限约束 |
| 运费券 | 抵扣运费 | 不抵扣商品金额 |

## 用券规则要点

1. 优惠券面额超过商品实付金额时，超出部分**不找零、不退余额**；
2. 使用优惠券的订单发生部分退款时，优惠券**不退还**；全额退款且订单未完结的，符合券规则的优惠券可退回（有效期不变）；
3. 退款金额 = 实付金额按比例分摊后退款（含用券分摊），不是商品标价原额；
4. 每笔订单最多叠加 **1 张平台券 + 1 张店铺券 + 1 张运费券**，活动另有说明的除外。

## 满减与折扣

- 跨店满减按**商品实付比例分摊**，退货时按分摊后的实际支付额退款；
- 限时秒杀价不含价保、不与优惠券叠加（除非页面说明可叠）；
- 赠品随主商品退货时需一并退回；赠品已使用或缺失的，可能从退款中扣除赠品价值。

## 会员权益

- 会员价与优惠券**可以叠加**（页面标注"不可叠加"的除外）；
- 会员运费券每月发放，当月有效不累计；
- 会员过期后，已领取未使用的会员专属券以券面有效期为为准。

## 常见问题

- 问：为什么退款金额比我付的少？
  答：多半是优惠券分摊——用券订单退款按分摊比例计算，明细可在退款进度页查看。
- 问：订单取消后优惠券去哪了？
  答：未完结订单取消，符合规则的优惠券自动退回账户，有效期不变；已过期的券不补发。
