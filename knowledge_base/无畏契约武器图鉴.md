 # 无畏契约武器图鉴
 
 ## 武器分类
 
 无畏契约中的武器分为：**手枪**、**冲锋枪**、**霰弹枪**、**步枪**、**狙击枪**、**机枪**。不同武器适合不同的经济局和战斗距离。
 以下武器名称格式为：**国服ID / 外服ID(英文)**。
 
 ## 护甲系统
 - **轻型护甲(Light Shields)**：600信用点，提供25点护甲值，减免部分身体伤害
 - **重型护甲(Heavy Shields)**：1000信用点，提供50点护甲值，减免更多伤害
 - 有甲时，多数步枪无法一枪爆头击杀，但正义和蜂刺可以一枪头击杀有甲敌人

 # 手枪类
 
 ## 标配 / Classic
 - **价格**：免费（默认手枪）
 - **伤害**：身体49 / 头部78
 - **射速**：半自动
 - **弹匣**：12发
 - **特点**：开局默认手枪。右键可以切换三连发模式，近距离爆发伤害可观。手枪局标配。
 - **使用建议**：手枪局主武器。近距离开右键三连发有奇效，中距离用左键精准点射。
 
 ## 短喷 / Shorty
 - **价格**：150信用点
 - **伤害**：身体40 / 头部80（近距离）
 - **弹匣**：2发
 - **特点**：近距离杀伤极高，但只有两发子弹。换弹速度较慢。
 - **使用建议**：Eco局近角阴人。配合技能近身使用。适合防守方在角落伏击。
 
 ## 狂怒 / Frenzy
 - **价格**：450信用点
 - **伤害**：身体39 / 头部78
 - **射速**：全自动
 - **弹匣**：13发
 - **特点**：全自动手枪，射速快但精准度一般。跑打精度相对较好。
 - **使用建议**：手枪局可以当微型步枪使用。适合近距离快速泼水。
 
 ## 鬼魅 / Ghost
 - **价格**：500信用点
 - **伤害**：身体30 / 头部105
 - **弹匣**：15发
 - **特点**：带消音器，击杀不显示击杀回放位置。一枪头可以秒杀无甲敌人。精准度高。
 - **使用建议**：手枪局最佳选择之一。消音效果在混战中很有优势。适合精准瞄准的玩家。
 
 ## 正义 / Sheriff
 - **价格**：800信用点
 - **伤害**：身体55 / 头部159
 - **弹匣**：6发
 - **特点**：手枪中伤害最高，一枪头秒杀有甲敌人。后坐力大，射速慢，需要精准瞄准。
 - **使用建议**：适合爆头精准的玩家。Eco局翻盘神器。第二局半买局强力选择。

 # 冲锋枪类
 
 ## 蜂刺 / Stinger
 - **价格**：950信用点
 - **伤害**：身体27 / 头部67
 - **射速**：高
 - **弹匣**：20发
 - **特点**：射速快但精准度一般。右键可以切换瞄准模式，射速降低但精准度提升。
 - **使用建议**：Eco局或半甲局近距离作战。右键瞄准模式适合中距离点射。
 
 ## 骇灵 / Spectre
 - **价格**：1600信用点
 - **伤害**：身体26 / 头部66
 - **射速**：中高
 - **弹匣**：30发
 - **特点**：全能型冲锋枪，中近距离表现稳定。跑打精度在冲锋枪中最好。带消音器。
 - **使用建议**：半甲局首选武器。中近距离跑打效果最佳。消音效果适合绕后。

 # 霰弹枪类
 
 ## 雄鹿 / Bucky
 - **价格**：900信用点
 - **伤害**：近距离极高（每颗弹丸约40身体伤害）
 - **弹匣**：5发
 - **特点**：泵动式霰弹枪，近距离一发入魂。右键可以发射燃烧弹，远距离有AOE效果。
 - **使用建议**：Eco局防守位近角。右键燃烧弹可以远距离骚扰。换弹较慢，注意时机。
 
 ## 判官 / Judge
 - **价格**：1850信用点
 - **伤害**：近距离极高
 - **弹匣**：7发
 - **特点**：全自动霰弹枪，近距离连射压制力极强。跑打效果好。
 - **使用建议**：防守方近角利器。在封烟后冲入敌阵有奇效。近点连续击杀能力强。

 # 步枪类（核心武器）
 
 ## 幻影 / Phantom
 - **价格**：2900信用点
 - **伤害**：身体39 / 头部156
 - **射速**：11发/秒
 - **弹匣**：30发
 - **穿墙伤害**：中等
 - **特点**：带消音器，不显示击杀回放。射速快，后坐力小，弹道稳定。中近距离表现极佳。远距离身体需要4枪击杀。
 - **适用场景**：适合中近距离交火。跑打精度优于Vandal。消音效果在混战中很有优势。新手推荐首选步枪。
 - **弹道控制**：前4发基本在一个点，第5发开始轻微上抬。适合连发和扫射。
 
 ## 狂徒 / Vandal
 - **价格**：2900信用点
 - **伤害**：身体39 / 头部160
 - **射速**：10发/秒
 - **弹匣**：25发
 - **穿墙伤害**：较高
 - **特点**：一枪头在任何距离都是致命的。后坐力比Phantom大但伤害不衰减。远距离身体需要4枪。
 - **适用场景**：适合中远距离对枪。爆头击杀效率极高。需要较好的压枪和瞄准能力。
 - **弹道控制**：前3发精准，第4-5发垂直上抬明显。适合点射和短连发。
 
 ### 幻影 vs 狂徒选择指南
 | 对比维度 | 幻影 | 狂徒 |
 |---------|-------------|-------------|
 | 一枪头秒杀 | 否(近距156需2枪头) | 是(160一枪头) |
 | 有效距离 | 中近距离 | 全距离 |
 | 射速 | 11发/秒(更快) | 10发/秒 |
 | 后坐力 | 较小，易控制 | 较大，需压枪 |
 | 消音效果 | 有(不显示击杀回放) | 无 |
 | 弹匣容量 | 30发 | 25发 |
 | 推荐玩家 | 新手、喜欢跑打 | 进阶、擅长爆头 |
 
 ## 獠犬 / Bulldog
 - **价格**：2050信用点
 - **伤害**：身体35 / 头部115
 - **射速**：中
 - **弹匣**：24发
 - **特点**：价格实惠的半经济步枪。右键可以开启瞄准镜模式，切换为三连发。
 - **使用建议**：半甲半枪局的经济选择。三连发模式适合中距离架枪。
 
 ## 戍卫 / Guardian
 - **价格**：2250信用点
 - **伤害**：身体65 / 头部195
 - **弹匣**：15发
 - **特点**：半自动步枪，一枪头秒杀任何护甲敌人。精准度极高但容错率低。
 - **使用建议**：适合瞄准能力强的玩家。中远距离架枪效果极佳。第二局强起局优选。

 # 狙击枪类
 
 ## 飞将 / Marshal
 - **价格**：950信用点
 - **伤害**：身体70 / 头部202
 - **弹匣**：5发
 - **特点**：轻狙，一枪头秒杀任何敌人。移动速度快，开镜后移动速度较慢。射速较快。
 - **使用建议**：Eco局狙击首选。适合快速开镜架枪。移动灵活可以快速转点。

 ## 莽侠 / Outlaw
 - **价格**：2400信用点
 - **伤害**：身体140 / 头部238 / 腿部119
 - **弹匣**：2发
 - **特点**：双管半自动中狙，价格介于飞将和冥狙之间。打完一发后可快速抛壳上膛打第二发。身体伤害140，无法一枪秒杀满血敌人（差一点），但可以秒杀残血。各距离伤害一致。
 - **使用建议**：定位是"惩罚型"狙击枪——配合队友补伤害，或收割包点残血。两发点射节奏快，架包点通道性价比高。不适合当主狙硬架长道，满血敌人需要两枪。

 ## 追猎
 - **价格**：600信用点
 - **类别**：佩枪（手枪类，2026赛季新武器）
 - **特点**：高性价比经济过渡枪，主打中近距离。据官方介绍具备不错的瞬时伤害，对轻甲敌人有较强压制力；远距离乏力，不适合对枪远点。
 - **使用建议**：手枪局与Eco局的新选择：价格只比鬼魅贵100，中近距离火力更猛。适合存钱阶段当主力，或残局捡漏补枪。详细伤害数值以游戏内实际为准（新枪数据可能随版本调整）。
 
 ## 冥狙 / Operator
 - **价格**：4700信用点
 - **伤害**：身体120 / 头部255
 - **弹匣**：5发
 - **特点**：重狙，一枪身体或头部即可击杀。开镜后视野变窄但精准度极高。价格昂贵，是控图利器。
 - **使用建议**：全价局核心狙击武器。一枪身体击杀的效率极高。适合控点和卡位。注意架枪时机不要浪费经济优势。
 - **操作技巧**：开镜后左右移动架枪，击发后立即关镜躲避。用Q键快速切换武器取消开镜。

 # 机枪类
 
 ## 战神 / Ares
 - **价格**：1600信用点
 - **伤害**：身体30 / 头部72
 - **弹匣**：50发
 - **特点**：轻机枪，射速快弹匣大。右键可以架设提升精准度。穿墙效果好。

 ## 奥丁/ Odin
 - **价格**：3200信用点
 - **伤害**：身体38 / 头部95
 - **弹匣**：100发
 - **特点**：重机枪，超大弹匣和极高射速。开火时移动极慢。穿墙伤害很高。
 - **使用建议**：适合封锁通道和大量穿墙压制。防守方弹药库。心理压制效果极佳。注意开火时的巨大声音暴露位置。

 # 近战武器

 - **价格**：免费(默认近战)
 - **伤害**：左键34身体/头部，右键重击68身体/头部

 # 武器选择策略
 
 ## 经济局(Eco Round)
 - 全队经济不足时，选择手枪+技能作战
 - 全Eco：标配(免费)或狂怒
 - 强Eco：鬼魅或正义
 - 半Eco冲锋枪：蜂刺
 
 ## 半甲半枪局
 - 半甲 + 冲锋枪或半经济步枪
 - 推荐配置：半甲+幽灵或半甲+蜂刺
 - 总花费约：2200-2650信用点
 
 ## 全甲全枪局(Full Buy)
 - 核心武器：幻影或狂徒
 - 狙击手：冥狙
 - 标配：步枪 + 重甲 + 技能(约500) ≈ 4400信用点
 
 ## 武器购买优先级建议
 1. 全甲局(有经济)：重甲+步枪 > 技能 > 多余道具
 2. 半甲局(经济有限)：半甲+半自动步枪 > 技能
 3. 手枪局：鬼魅 > 正义 > 狂怒
 4. 狙击手：冥狙优先于重甲(技能充足时)
 
 ## 武器伤害穿透等级
 - 重型武器(步枪/狙击/机枪)：穿墙伤害高，可穿透多数材质
 - 中型武器(冲锋枪/部分手枪)：穿墙伤害中等
 - 轻型武器(手枪/霰弹枪)：穿墙伤害低
