# 无畏契约排位上分指南

> 最后核对：2026-09-17
> 段位与排位规则以当前赛季官方说明为准。

从段位机制、英雄池、心态到复盘方法的系统性上分攻略。

## 一、排位机制

- **段位阶梯**（低到高）：黑铁 → 青铜 → 白银 → 黄金 → 铂金 → 钻石 → 超凡入圣 → 神话 → 辐能战魂。
- 每个大段位内分 1~3 小段，用评分（RR）累积晋级；钻石以上评分扣得更严。
- **定级赛**：新赛季需要先打定级赛才会显示段位；具体场次以当前赛季客户端说明为准。
- **隐藏分（MMR）**：系统内部评估你的真实水平，长期表现决定你的加减分速度。
- **组队限制**：不同段位和模式的组队人数限制不同，排位前以客户端实际限制为准。
- 挂机、消极游戏会被扣评分甚至禁赛。

## 二、上分英雄池建议

**原则：池子窄而精 > 宽而浅。** 熟练 2~3 个英雄远胜于"每个都会一点"。

| 定位 | 低段位推荐（白银~黄金） | 中高段位推荐（铂金~钻石+） |
|------|------|------|
| 决斗 | 芮娜（单挑靠枪法）、雷兹（技能强） | 捷风（上限高）、夜露（信息欺诈） |
| 先锋 | 斯凯（治疗+侦察容错高）、猎枭 | 黑梦、钛狐（地图级压制） |
| 烟位 | 炼狱（点烟直观）、幽影（灵活） | 蝰蛇（区域封锁）、暮蝶（死后还有贡献） |
| 哨位 | 贤者（治疗+复活）、奇乐 | 零（信息）、尚勃勒（枪法型）、维斯 |

**新手英雄选择问答**：
- 枪法好但没意识 → 芮娜、尚勃勒（技能简单，枪法说话）
- 意识好但枪法一般 → 零、黑梦、炼狱（信息与控制位）
- 完全新手 → 贤者、炼狱、斯凯（容错率最高的三人组）

## 三、各段位瓶颈与突破点

| 段位段 | 普遍瓶颈 | 突破方法 |
|------|------|------|
| 黑铁~白银 | 枪法不够、乱跑乱开枪 | 每天死斗练10分钟；学会急停再开枪 |
| 白银~黄金 | 没有团队概念、各自为战 | 学会跟队买经济、报点、别单浪 |
| 黄金~铂金 | 枪法到位但没有战术 | 学看小地图、控中路、技能配合 |
| 铂金~钻石 | 个人能力接近上限 | 深耕2~3个英雄、研究道具点位、看复盘 |
| 钻石+ | 心态与细节 | 减少上头、复盘每次败局、固定车队 |

## 四、上分实战技巧

1. **固定时间、固定英雄池**：一天最多连打3~5场，累了必停。连败2场立刻休息，"上头排"是掉分最大来源。
2. **学会看经济面板**：按Tab看全队经济，指挥eco/强起。经济好=阵容好=胜率+10%。
3. **地图池专精**：当期竞技图池只有约7张图，把图池内地图的道具点位练熟，比泛泛打全图高效得多。
4. **开局报阵容**：选人阶段沟通阵容（1决斗1先锋1烟2自由），缺先锋的阵容信息全靠白给。
5. **赢回合优先于拿人头**：下包300全队、拆包赢回合——很多低段位玩家赢了击杀输了回合。
6. **不要依赖未证实的失败保护**：目前没有找到通用的失败减半扣分机制，不要把它当成上分策略。
7. **复盘黄金三问**（每场败局问自己）：
   - 我哪个回合死得最冤？为什么？（走位问题还是信息问题）
   - 我经济决策对了吗？（有没有乱强起/乱eco）
   - 我的技能在关键回合交出来了吗？

## 五、心态管理

- **排位是长跑**：胜率55%就已经在上分，输一场不代表白玩。
- **屏蔽干扰**：遇到消极队友直接静音，别对喷——对喷的局基本必输。
- **别盯着评分打**：盯着"这局加多少分"会变形，专注每一回合的决策质量。
- **换环境**：连败时打两把死斗或娱乐模式冷静一下，比硬排更高效。

## 六、上分练功计划（每天30~60分钟）

| 时间 | 内容 |
|------|------|
| 10分钟 | 死斗模式热身（2~3场），练急停和头线 |
| 5分钟 | 训练场：主战武器压枪弹道练习 |
| 20~40分钟 | 排位（最多3场，连败2场停） |
| 5分钟 | 回看一场败局的关键回合（死亡回放视角） |

## 七、常见问题

- **Q：单排好还是组队好？**
  A：低段位单排练个人能力，中高段位组队（车队）胜率普遍更高——沟通成本更低。

- **Q：定级赛定低了怎么办？**
  A：隐藏分会让你连胜快速跳段（加分多），专心打胜率即可。

- **Q：要不要专练狙击手？**
  A：冥驹需要队友"供养"（4700元），低段位队友不会让经济，建议先练步枪，段位高了再转狙。
